# Weather_Analytics

A Weather Analytics Dashboard built using Python, ETL Pipeline, PostgreSQL, and Streamlit. The project collects real-time weather data from a weather API, transforms and stores it in a PostgreSQL database, and provides interactive visualizations and insights through a Streamlit dashboard.

# Project Overview

This project demonstrates an end-to-end data analytics workflow:

1.Extract weather data from an API.
2.Transform the data into a structured format.
3.Load the processed data into PostgreSQL.
4.Analyze and Visualize weather trends using Streamlit.

The dashboard helps users monitor weather conditions and analyze patterns such as temperature, humidity, wind speed, and atmospheric pressure.
